📊 Google Sheets કનેક્શન & સિંક

ગૂગલ શીટ્સ સાથે રિયલ ટાઈમ બેકઅપ અને સિંક માટે

તમારી Google Sheet સાથે જોડાયેલ Apps Script Webhook URL અહીં નાખો.

Google Apps Script કોડ (Code.gs) 
function doPost(e) {
  var SHEET_ID = "1RIhoyCwPXG9Z6sQVABJkL9cx3UhCaZLA3n7EPE9OL50";
  var ss = SpreadsheetApp.openById(SHEET_ID);
  var sheet = ss.getSheetByName("Transactions") || ss.insertSheet("Transactions");
  var data = JSON.parse(e.postData.contents);
  var typeLabel = (data.type === "income") ? "આવક (Income)" : "ખર્ચ (Expense)";
  var p1 = (data.p1Share !== undefined) ? data.p1Share : (data.p1_share || 0);
  var p2 = (data.p2Share !== undefined) ? data.p2Share : (data.p2_share || 0);
  sheet.appendRow([
    data.id, data.date, data.month, typeLabel, data.property || "-",
    data.tenant || "-", data.category || "-", Number(data.amount || 0),
    Number(p1), Number(p2), data.paymentMode || "-", data.remarks || "-"
  ]);
  return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}

📝 ગૂગલ શીટ્સ સાથે જોડવાની સરળ રીત:

  1. નવી Google Sheet બનાવો અને Extensions > Apps Script ખોલો.
  2. ઉપરનો કોડ કોપી કરી પેસ્ટ કરો અને સેવ કરો.
  3. Deploy > New deployment > Web app પસંદ કરો (Who has access: "Anyone").
  4. મળેલ વેબ એપ URL અહીં સેવ કરો. દરેક એન્ટ્રી આપોઆપ શીટમાં રેકોર્ડ થશે!
